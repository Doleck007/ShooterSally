# Top-down Shooter — Project Brief

## Purpose
Provide a small, extensible Unity top-down shooter prototype used for learning and tutorial purposes. Demonstrate player controls, input handling, movement, basic AI/nav, and polish-ready project structure.

## Objectives
- Implement responsive player movement and input mapping.
- Show a clean project structure and documentation for learners.
- Keep systems modular so features can be extended independently.

## Scope
In-scope:
- Player input & movement
- Basic enemy AI and navigation (navmesh or simple steering)
- Shooting mechanics and basic combat feedback
- Simple UI (health, score)
- Clear documentation and example scenes

Out-of-scope:
- Multiplayer networking
- Advanced procedural content
- Polished art pipeline (prototype art only)

## Success Criteria
- Playable sample scene demonstrating movement and combat.
- Well-documented code and memory-bank describing architecture and next steps.
- Easy-to-follow tutorial steps for contributors.

## Constraints & Assumptions
- Unity 2021+ with the Input System package available.
- Project kept small and educational; performance is secondary to clarity.
- Memory Bank (memory-bank/) will contain all project documentation for continuity.

## Deliverables
- Playable SampleScene
- Memory-bank with core documentation files
- Source code with comments and patterns documented
